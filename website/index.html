Pentru permisul de barca

Pregatire pentru CAA Clasa C si Clasa D.

Aplicatia este gandita pentru candidatii care se pregatesc pentru examenul de conducator de ambarcatiuni de agrement si vor o metoda simpla de repetare zilnica.

  • intrebari organizate pe subiecte usor de parcurs;
  • mod examen pentru verificarea nivelului de pregatire;
  • mod practica pentru consolidarea raspunsurilor gresite;
  • date pastrate local pe dispozitiv.

Confidentialitate

Datele tale raman pe dispozitiv.

Chestionare Barca nu colecteaza informatii personale. Progresul, istoricul si setarile sunt pastrate local si pot fi sterse oricand din aplicatie.

Intrebari frecvente

Raspunsuri rapide inainte sa incepi.

Aplicatia este pentru permis barca CAA?

Da. Este construita pentru pregatirea examenului de conducator de ambarcatiuni de agrement, Clasa C si Clasa D.

Pot invata fara internet?

Da. Modul fara internet iti permite sa continui sesiunile de practica si cand nu ai conexiune.

Exista mod de simulare examen?

Da. Simularea include 26 de intrebari, cronometru si rezultat final cu detalii pentru raspunsurile gresite.
